# OpenClaw Debugger

OpenClaw Debugger 是一个 Windows 桌面工具，用于管理 OpenClaw 服务器中的记忆文件、表情包、模型配置和服务器快照。

## 功能

- **概览**：查看连接状态、服务器信息和备份进度。
- **记忆**：浏览、编辑和保存服务器中的记忆文档，并进行版本冲突检查。
- **表情包**：
  - 支持 PNG、JPG、JPEG、GIF、WEBP、BMP。
  - 支持选择文件或拖拽上传；GIF 可直接播放预览。
  - 支持缩略图、重命名、标签、权重和目录自动登记。
  - 上传支持暂停、取消、失败重试和断点续传。
  - 单文件上限 30 MiB，并检查文件名、格式、图片尺寸和路径安全。
  - 支持按名称和标签筛选；新图片会自动登记到目录。
- **模型**：
  - 查看当前模型、备选模型和最近一次延迟结果。
  - 批量测试模型延迟，显示首响应时间和超时状态。
  - 拖拽调整模型顺序，调整后自动同步服务器配置。
  - 支持按提供商、延迟和状态筛选。
- **主题**：切换主题，调整背景泛白、模糊程度和界面颜色。
- **服务器备份**：
  - 创建服务器根文件系统的 tar.gz 快照。
  - 显示总大小、传输进度、速度、预计剩余时间和当前阶段。
  - 支持暂停、继续、取消以及网络中断后的断点续传。
  - 完成后校验压缩包并生成 SHA-256。

远程操作会进入统一队列，连接、备份、上传、文件编辑和模型测试不会同时占用 SSH 会话；队列会显示等待、运行、暂停、取消、失败和完成状态。

## 运行要求

- Windows 10 或更高版本。
- Windows OpenSSH Client。
- Microsoft WebView2 Runtime。
- 服务器已安装 OpenClaw、Python 3 和用于创建归档的 tar、gzip 工具。
- 当前 Windows 用户能够通过 SSH 登录服务器；服务器账户需要具备读取和维护目标目录的权限。

## 使用方法

1. 从 GitHub Releases 下载并解压程序包。
2. 双击 OpenClawDebugger.exe。
3. 在“设置”中填写服务器主机、SSH 端口、用户名、OpenClaw 工作区路径和表情包目录路径。
4. 点击连接。连接成功后，记忆、表情包和模型信息会自动读取。
5. 需要创建快照时，在“概览”中点击“备份服务器”。

程序使用系统 SSH 客户端进行连接。请在运行前确认 SSH 登录已经配置完成，不要将私钥、令牌或其他凭据放入程序目录或 Git 仓库。模型 API 密钥由 Windows Credential Manager 管理，私密目录只保存设置、日志、缓存和索引。

## 数据与隐私

本地设置、操作日志、缩略图缓存、上传临时文件、回滚快照和服务器备份保存在仓库目录之外的私有数据目录中。

项目不会要求把服务器地址、私钥或访问令牌写入源码。发布或提交前，请确认这些信息没有出现在配置文件、日志和截图中。

## 备份说明

每个快照目录通常包含：

- server-rootfs.tar.gz：服务器根文件系统归档。
- snapshot-manifest.json：创建时间、归档大小、SHA-256 和一致性信息。

这是在线文件级归档。服务器文件在读取期间可能发生变化，因此它不等同于磁盘或卷级原子快照。恢复时请使用适合你的运维工具解压和检查归档。

默认会排除 /proc、/sys、/dev 和 /run 等运行时目录。备份保留数量可以在设置中调整。
